================================================================================
「Pages 是否從這個 repo 發佈」是什麼意思？
================================================================================

GitHub Pages = 用 GitHub 幫你把「儲存庫裡的檔案」當成一個靜態網站，給一個網址
（例如 https://donaldcpk.github.io/nwcs-matsa/）。

「從這個 repo 發佈」= 網頁內容來自 **同一個** GitHub 儲存庫（nwcs-matsa），不是別台主機。

這很常見：個人專案、說明文件、遊戲網頁版都常這樣用。

================================================================================
main 和 master（你專案裡曾出現的狀況）
================================================================================

GitHub Pages 設定裡若寫「從 **main** 分支建置」，那只有 **main 分支上的檔案**
會出現在網站上。若你程式只推在 **master**，網站可能還是舊的。

請讓 **main** 與你開發分支內容一致（例如合併後 push main）。

================================================================================
公開儲存庫 + Pages：安全要心里有數
================================================================================

- 任何人可 clone、可看檔案；**不要**把 service_role、學生密碼表、真實名冊 SQL 放進 repo。
- anon/publishable 金鑰出現在網頁與 repo 是常態，防線在 Supabase **RLS**。
- 教師電郵若寫在已追蹤的 `school-auth-config.defaults.js`，在**公開** repo 裡也會被看到；
  若不能接受，請改**私人儲存庫**，或自行研究用 GitHub Actions + Secrets 在建置時注入。
