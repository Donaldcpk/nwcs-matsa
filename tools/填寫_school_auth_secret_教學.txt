================================================================================
為什麼要填 school-auth-config.secret.js？和 plugins.js 有什麼關係？
================================================================================

遊戲有「兩段」會連到 Supabase：

1) 一進網頁時的「學校登入畫面」（school-auth-gate.js）
   → 還沒載入 RPG Maker，所以讀不到 plugins.js 裡的插件參數。
   → 必須從 school-auth-config.secret.js 讀取網址與金鑰，才能登入。

2) 進入遊戲後的「全知圖鑑／世界排名」（OmniscientEncyclopedia 插件）
   → 參數在 js/plugins.js 的 OmniscientEncyclopedia 那一列。

兩邊的「網址」和「金鑰」必須是同一組專案，否則登入用 A 專案、排行榜卻打 B 專案，會錯亂。

================================================================================
對照表：plugins.js → school-auth-config.secret.js
================================================================================

在 js/plugins.js 找到 name 為 "OmniscientEncyclopedia" 的那一筆，裡面有 parameters：

  supabaseUrl   →  寫進 secret 的  supabaseUrl    （一模一樣複製）
  supabaseKey   →  寫進 secret 的  supabaseAnonKey（一模一樣複製）

注意：plugins 裡叫 supabaseKey，secret 檔裡欄位名稱是 supabaseAnonKey，只是命名不同，內容要相同。

以下三項「沒有」在 plugins.js 裡，是給登入畫面／教師身分用的，請依你學校實際情況填：

  adminAuthEmail    學生在登入畫面只打 admin 時，會當成這個信箱去登入。
  adminEmails       所有要用「教師檢視排行榜」（看別人登入信箱）的帳號，信箱要列在這裡，
                    且須與 Supabase Authentication 裡建立的老師帳號一致。
  studentEmailDomain  學校電郵網域，例如 xxx.edu.hk（僅提示用，真正擋名冊在資料庫）。

================================================================================
操作步驟（最簡）
================================================================================

1. 用編輯器打開 js/plugins.js，搜尋 OmniscientEncyclopedia，複製 supabaseUrl、supabaseKey。

2. 打開 js/school-auth-config.secret.js（若沒有，先複製：
     cp js/school-auth-config.secret.EXAMPLE.js js/school-auth-config.secret.js
   ）

3. 把 Object.assign 裡的值改成：
     supabaseUrl:     （貼上 plugins 的 supabaseUrl）
     supabaseAnonKey: （貼上 plugins 的 supabaseKey）
     adminAuthEmail / adminEmails / studentEmailDomain 依學校填好。

4. 存檔後重新整理網頁測試登入。

================================================================================
常見問題
================================================================================

Q：只改 plugins.js 可以嗎？
A：不行。登入畫面比遊戲更早執行，只認 secret.js。

Q：secret.js 會不會被 Git 上傳？
A：專案根目錄 .gitignore 已排除 school-auth-config.secret.js；上傳前可用
   git status 確認沒有出現這個檔案被加入。
