# 數學挑戰（testingX6）

伍華學生用的數學 RPG。戰鬥時看題目，選 A 到 D。有原圖的題用原圖；沒有原圖、但答案表有答案的題，會用 LaTeX 畫成題卡。

## 特色功能

- 開場先選年級，再選範圍（數與代數、圖形與空間、數據處理），然後選課題。選好遊戲才開始。
- 課題用課本名稱，例如「有向數」「求積法（一）」。標了 A+G 的課題，兩個範圍都會出現。
- 選單裡也有「選擇課題」，隨時可以換。
- 換課題後，從那一課的第 1 題開始。
- 有照片的題來自 `AIQbank.zip`。沒有照片的題，用題目文字和 LaTeX 畫成題卡。
- 答案來自 `Answer Key S1-6.xlsx`。答案表空白的題不會出現。

## 安裝與執行

1. 用 RPG Maker MZ 打開這個資料夾。
2. 按「遊戲測試」。
3. 網頁版打開即可遊玩，不用登入。

## 使用說明

1. 輸入名字。
2. 選年級：中一到中六。
3. 選範圍：數與代數、圖形與空間，或數據處理。
4. 選課題。例如中一的數與代數會看到「1 基礎計算」「2 有向數」。
5. 如果這一課同時有中文和英文，再選一種。選好後遊戲才開始。
6. 之後去戰鬥，畫面會顯示那一課的題目。有原圖就顯示原圖；沒有原圖就顯示 LaTeX 題卡。題目太寬時會縮小到答題按鈕上面，整題都看得到。右上角的剩餘時間在答題時會移到下方，不會擋住題目或圖。

中四到中六現在也可以玩。課題名稱依照題目內容，例如中四的 `4A01` 是「複數」，中六的「線性規劃」是題檔 `603`。

`4A06`（續多項式）答案表沒有答案，所以還沒放進遊戲。有些題寫「圖中」，但原來的圖檔不存在。這種題仍會出現文字和公式，只是少了那張圖。

同一課如果標成 A+G，會同時出現在「數與代數」和「圖形與空間」。

無限之塔的塔主選單改成「選擇課題」。選完才會沿用原本的進塔流程。

## 架構總覽

- `js/plugins/questionDatabase.js`：題目清單。每一課用 `1A01_CH`、`1A01_EN` 這種名字分開。
- `img/pictures/AIQ/`：原本的題目圖片。
- `img/pictures/AIQ/TEXT/`：沒有原圖時，用 LaTeX 畫出來的題卡。
- `js/plugins/MZQuizzer.js`：出題，以及「選擇課題」畫面。
- `tools/import_aiqbank.py`：匯入有原圖的題。
- `tools/render_text_questions.py`：把沒有原圖的題畫成 LaTeX 題卡。

## 重新匯入題庫

把新的壓縮檔和答案表準備好，在專案資料夾執行：

```bash
python3 tools/import_aiqbank.py
```

預設讀取：

- `/Users/cdlanod/Documents/RMMZ/AIQbank.zip`
- `/Users/cdlanod/Downloads/Answer Key S1-6.xlsx`

只會留下「答案是 A 到 E」而且「找得到圖片」的題。結果寫進 `tools/output/aiq_import_report.json`。

沒有原圖、但題目是文字的課題，在專案資料夾再執行：

```bash
python3 tools/render_text_questions.py
```

這支程式讀取 `/Users/cdlanod/Documents/MATH ARPG 2.0/QuestionBank`，把公式畫進題卡。已經有原圖的課題不會重畫。

## 測試方法

1. 新遊戲，選中一、中文、`1A01`。
2. 打一場會出題的戰鬥，確認畫面是 `1A01` 的圖，而不是舊題或 TSA。
3. 打開選單，改選 `1A03`，再打一場，題目要換成那一課，而且從第 1 題開始。
4. 選一個只有中文的課題（例如 `1B07`），確認英文清單裡沒有它。
